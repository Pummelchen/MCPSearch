# B81 — `mcp_smoke.py` de-chunked an SSE body after decoding it to `str`

Host: this Mac (arm64, macOS 26.6.2) · branch audit/2026-09-13

## What was wrong

`http_exchange` decoded the whole response and then applied the chunk header's *byte* count to
the resulting `str`:

```
    text = raw.decode("utf-8", "replace")            # scripts/mcp_smoke.py:319 (pre-fix)
    head, _, rest = text.partition("\r\n\r\n")       # :320
    ...
    size = int(remaining[:index].split(";")[0], 16)  # the hex BYTE count from the chunk header
    pieces.append(remaining[index + 2 : index + 2 + size])
    remaining = remaining[index + 2 + size + 2 :]
```

Every non-ASCII character shrinks the decoded `str` relative to the byte stream, so a chunk
boundary taken from the byte count lands in the wrong place and the recovered SSE stream is
truncated or corrupted. Swift's `JSONEncoder` emits raw UTF-8, so a tool result containing any
non-ASCII text would trip this. It was latent in CI only because the smoke payloads are ASCII.

## The decision

Frame the bytes before decoding. Partition `raw` on the byte `\r\n\r\n`, decode only the status
line and headers, run the existing de-chunk loop over `bytes`, and decode the reassembled body
once. `http.client` would do the framing for us, but this helper deliberately speaks raw HTTP
over a socket (the probe is pinned to loopback — ledger A08), so the de-chunk loop stays; only
the type it operates on changes.

The local for the raw body is named `raw_body`, not `body`, because `body` is already the
`dict[str, Any]` request parameter of `http_exchange`.

## Verification

The check below calls the real `http_exchange` with `socket.create_connection` stubbed to return
one chunked SSE response. The body is a JSON-RPC message whose `note` is `é日本語`, and the chunk
boundary is placed inside the first multi-byte character (`日`). `é` earlier in the payload is a
complete multi-byte character, so a decoded-then-framed body loses a character's worth of offset
and the whole message is dropped.

RED was produced by temporarily reverting the hunk in `scripts/mcp_smoke.py` to its pre-fix form,
then restored; the gates below ran on the restored file.

```
$ python3 - <<'PY'
import importlib.util, json, socket

spec = importlib.util.spec_from_file_location("mcp_smoke", "scripts/mcp_smoke.py")
smoke = importlib.util.module_from_spec(spec)
spec.loader.exec_module(smoke)

expected = {"jsonrpc": "2.0", "id": 2, "result": {"note": "\u00e9\u65e5\u672c\u8a9e"}}
sse = f"data: {json.dumps(expected, ensure_ascii=False)}\n\n".encode()
at = sse.index("\u65e5".encode()) + 1     # the chunk boundary splits the first multi-byte character
chunked = b"".join(f"{len(c):x}\r\n".encode() + c + b"\r\n" for c in (sse[:at], sse[at:]))
raw = (
    b"HTTP/1.1 200 OK\r\nContent-Type: text/event-stream\r\n"
    b"Transfer-Encoding: chunked\r\nConnection: close\r\n\r\n" + chunked + b"0\r\n\r\n"
)

class FakeConnection:
    _pending = raw

    def __enter__(self) -> "FakeConnection":
        return self

    def __exit__(self, *exc: object) -> bool:
        return False

    def sendall(self, data: bytes) -> None:
        pass

    def recv(self, size: int) -> bytes:
        data, self._pending = self._pending, b""
        return data

socket.create_connection = lambda *a, **k: FakeConnection()  # type: ignore[assignment]
try:
    status, _, messages = smoke.http_exchange(0, {"jsonrpc": "2.0", "id": 2, "method": "ping"})
    assert status == 200, status
    assert messages == [expected], f"corrupted: {messages!r}"
    print("PASS: recovered", messages[0]["result"]["note"])
except Exception as error:
    print(f"FAIL: {type(error).__name__}: {error}")
    raise SystemExit(1)
```
