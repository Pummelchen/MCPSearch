## The coverage floor is a real check, not a number in a log

```
$ python3 scripts/coverage_floor.py "$PWD/Sources/" 80 coverage.json
Sources/ line coverage: 6864/8062 = 85.1 % (floor 80 %)   exit 0

$ python3 scripts/coverage_floor.py "$PWD/Sources/" 90 coverage.json
::error::Sources/ line coverage is 85.1 %, below the 90 % floor. …   exit 1
```

`scripts/coverage_floor.py` counts only paths under this repository's own `Sources/`: SwiftPM
instruments the dependency checkouts too, so an unfiltered total reads 40 % against 85.1 % for
the code this repository owns. It is linted and type-checked like the other scripts, so it
cannot rot unnoticed.
