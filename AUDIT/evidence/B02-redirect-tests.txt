## Boundary of the claim, measured rather than assumed

A redirect to `file://` is refused by URLSession/CFNetwork *before* the manual loop sees the 3xx:
the delegate is not consulted for a cross-scheme redirect, and the caller gets
"the transport reported error -1102". A probe with a readable /etc/hosts confirmed no part of the
file is returned (the file is readable by the test process: isReadableFile == true).
That gap — an opaque diagnosis resting on undocumented transport behaviour — is recorded
separately as B102.
