# B97 — `AnswerSynthesizer`'s completion edge cases, token usage and locale prompt were untested

Host: `node1 (arm64, macOS 26.6.2)` · branch `audit/2026-09-13` · Swift 6.3.3

## Premise check: still open

Grepped `Tests/` before writing. `AnswerSynthesizerTests` already covers the empty-content,
`INSUFFICIENT`, citation stripping/renumbering, credential placement, thinking-mode retry and the
auth/429/malformed/vendor-error HTTP arms, but nothing reached the four branches the record names:

* no test sends a body whose `choices` array is present but empty, so
  `guard let choice = decoded.choices?.first` had no coverage;
* `completion.inputTokens`/`outputTokens` are decoded on every response and never asserted — the
  fixture has always carried `usage` with `100`/`20`, and no test read the fields;
* `synthesize(query:results:)` is called without `locale:` everywhere, so
  `buildQuestion`'s locale sentence was reached only through `buildQuestion` itself (which nothing
  calls either);
* `describe(_:)` itself was never called: the auth/429/malformed/vendor-error tests all take the
  `HTTPResponse` path, and no mock throws `URLError` or `CancellationError`.

None of B70/B71/B93–B96/B54/B76/B79 touched this file or these tests, and
`git log --oneline --all --grep "audit(B97)"` is empty. The gap is real.

## What was added

Eight tests in the existing `AnswerSynthesizerTests.swift` (646 → 772 lines, well under the
1458-line ceiling, so no split was needed), plus one private `userTurn(in:)` fixture helper that
decodes the recorded request's last message:

| Test | Pins |
| --- | --- |
| `testAnEmptyChoiceArrayIsRefused` | 200 with `{"choices":[]}` → `synthesisFailed` whose `safeDescription` contains "no choices" |
| `testTokenUsageIsReported` | `answer.inputTokens == 100`, `answer.outputTokens == 20` from the response `usage` |
| `testLocaleInstructionReachesTheUserTurn` | `locale: "de-DE"` puts "Answer in the language implied by locale de-DE." in the user message |
| `testNoLocaleInstructionWithoutALocale` | `nil` and `""` both add no language instruction |
| `testTransportErrorsMapToCuratedMessages` | `describe(URLError(.timedOut))`→"The synthesis model timed out."; `.cancelled`→"The request was cancelled."; the five unreachable codes (`.notConnectedToInternet`, `.networkConnectionLost`, `.cannotConnectToHost`, `.dnsLookupFailed`, `.cannotFindHost`)→"The synthesis model could not be reached."; any other code→"The synthesis request failed." |
| `testCancellationDuringSynthesisIsReportedAsCancelled` | a mock that throws `CancellationError` surfaces `synthesisFailed("The request was cancelled.")` |

The production code did not change. The `complete`/`describe`/`buildQuestion` seam the tests need —
an injectable `HTTPClient` and the internal `static describe` — already existed.
