# B80 — `soak.py` conflated EOF with a malformed stdout line and discarded the line

Host: this Mac (arm64, macOS 26.6.2) · branch audit/2026-09-13

## What was wrong

`Server.read()` returned `None` for two different events:

```python
line = self.process.stdout.readline()
if not line:
    return None                      # end of stream
try:
    return json.loads(line)
except json.JSONDecodeError:
    return None                      # a line that is not JSON
```

`Server.request()` maps that single `None` to `RuntimeError("server closed stdout")`, so a stray
non-JSON line on stdout — a corrupted protocol stream, which `mcp_smoke.py` treats as a hard
failure and quotes — was silently discarded and misdiagnosed as the server having closed stdout.
The offending line, the only thing that identifies the corruption, was thrown away.

## The fix

`None` now means end of stream only; a `JSONDecodeError` raises with the offending line attached:

```python
    def read(self) -> dict[str, Any] | None:
        """Next protocol message, or None only when stdout is at end of stream."""
        assert self.process.stdout is not None
        line = self.process.stdout.readline()
        if not line:
            return None
        try:
            return json.loads(line)
        except json.JSONDecodeError as error:
            # A line that is not JSON is a corrupted protocol stream, not end of stream:
            # returning None here let `request` discard the offending line and report a
            # closed stdout instead (ledger B80).
            raise RuntimeError(
                f"stdout is not valid JSON (protocol stream corrupted): {error}; "
                f"offending line: {line!r}"
            ) from error
```

## Verification

The check drives `Server.read()` over a fake process whose stdout is a `StringIO`: one case feeds
a non-JSON line and requires a `RuntimeError` naming that line, the other feeds an empty stream and
requires `None`.

RED against the unfixed code (temporary revert of the hunk above):

```

import io, sys
sys.path.insert(0, "scripts")
import soak

class FakeProcess:
    def __init__(self, line):
        self.stdout = io.StringIO(line)

def read_line(line):
    server = soak.Server.__new__(soak.Server)
    server.process = FakeProcess(line)
    return server.read()

try:
    read_line("this is not json\n")
except RuntimeError as error:
    assert "this is not json" in str(error), error
```
