# B22 — the Swift-version gate passed silently when the version could not be parsed

Host: MacBook-AB.local (arm64, macOS 26.6.2) · branch audit/2026-09-13

## What was wrong

```bash
# .github/workflows/ci.yml, "Verify Swift toolchain is at least 6.3" (before)
version="$(swift -version 2>&1 | sed -n 's/.*Swift version \([0-9]*\.[0-9]*\).*/\1/p' | head -1)"
echo "Detected Swift $version"
major="${version%%.*}"
minor="${version##*.}"
if [ "$major" -lt 6 ] || { [ "$major" -eq 6 ] && [ "$minor" -lt 3 ]; }; then
  echo "::error::This package requires swift-tools-version 6.3 or newer; found $version"
  exit 1
fi
```

`set -euo pipefail` is in force, but `[ "$major" -lt 6 ]` appears in an `if` condition, so its
non-zero status does not abort. With `version=""` both `[` tests fail with `integer expected`,
the whole condition is false, the `::error::` branch is skipped and the step exits **0** — the
gate passes on exactly the output-format change it exists to catch. The `sed` also allowed an
empty minor part (`[0-9]*`), so a bare `"6"` would have been read as `major=6, minor=6` and
accepted.

## Fails-before evidence

The step's `run` block is extracted from `ci.yml` with PyYAML (both the committed and the fixed
version) and replayed with a stubbed `swift` on `PATH`, so an unusual `swift -version` output
can be produced without an unusual toolchain:

```
$ replay.sh old "Swift 6.3.3 (swift-6.3-RELEASE)"      # no "version" keyword: unparseable
Swift 6.3.3 (swift-6.3-RELEASE)
Detected Swift
./old.sh: line 7: [: : integer expected
./old.sh: line 7: [: : integer expected
old exit: 0                                            # GATE PASSED, silently

$ replay.sh new "Swift 6.3.3 (swift-6.3-RELEASE)"
Swift 6.3.3 (swift-6.3-RELEASE)
::error::could not parse 'Swift version X.Y' from 'swift -version'; refusing to guess
new exit: 1
```

## The fix

An unparseable version is now a hard failure, and the pattern requires digits on both sides of
the dot so a bare major version cannot masquerade as `major.minor`:

```bash
version="$(swift -version 2>&1 | sed -n 's/.*Swift version \([0-9][0-9]*\.[0-9][0-9]*\).*/\1/p' | head -1)"
if [ -z "$version" ]; then
  echo "::error::could not parse 'Swift version X.Y' from 'swift -version'; refusing to guess"
  exit 1
fi
...
echo "Swift $version satisfies swift-tools-version 6.3"
```
