# B52 — a cancelled request leaked the half-open probe it claimed

Host: MacBook-AB.local (arm64, macOS 26.6.2) · branch audit/2026-09-13

## What was wrong

`ProviderHealth.authorize` claims the single half-open probe through
`CircuitBreaker.shouldAttempt()`, which sets `probeInFlight = true`
(`CircuitBreaker.swift:92`). The claim is released only by `recordSuccess` and `recordFailure`.

`SearchOrchestrator.runSingle` records a health outcome on every failure path *except* a bare
`CancellationError`:

```swift
} catch is CancellationError {
    result.failures.append(ProviderFailure(provider: id, category: .cancelled, message: "Request cancelled."))
    // no health call
}
```

So a search cancelled while the provider was half-open left `probeInFlight == true` for good: every
later `authorize` answered `.circuitOpen` ("being probed after failures"), and since no request is
ever admitted, nothing can ever clear it. The provider was dead to the process.

## Fails-before evidence

```swift
// SearchOrchestrator: remove the release from the cancellation path
- await health.releaseProbe(id)
```

```
$ swift test --filter testACancelledRequestReleasesTheHalfOpenProbe
error: ... the probe must have been released, got
  Optional(ProviderFailure(provider: .tavily, category: .circuitOpen,
  message: "Tavily is being probed after failures; this request is skipped until that probe finishes."))
```

## The fix

An explicit release, which records no outcome:

```swift
// CircuitBreaker
public func releaseProbe() {
    guard state == .halfOpen else { return }
    probeInFlight = false
}

// ProviderHealth
public func releaseProbe(_ provider: ProviderID) async {
    await breakers[provider]?.releaseProbe()
}
```

and the cancellation path calls it before appending its failure record. Recording the cancellation
as a *failure* would have released the probe too, but it would also count a failure against the
provider and set its last-error category — and a caller that goes away says nothing about the
provider, the same reasoning that keeps the whole-search deadline off the breaker (B12).
