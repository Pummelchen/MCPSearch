# CI follow-up — two of my own tests were environment-sensitive

Host: this Mac (arm64, macOS 26.6.2) · branch audit/2026-09-13

The CI run for B56 (`34755384370`) failed in the second test step — "Test again with placeholder
provider credentials present", which runs the whole suite once with placeholder keys in the
environment. The failure was my own B32 clamp test. Investigating it turned up a second, local
flake of my own making. Both are fixed here rather than explained away.

## B32 `testToolArgumentClampsAreEnforced` — ambient credentials changed the answer

The test starts a server pointed at the SearXNG stub and asserts `max_results: 50` yields exactly
20 results. But CI sets `TAVILY_API_KEY` and `BRAVE_SEARCH_API_KEY` to placeholders for that step, so
the child server also had Tavily and Brave configured: the `.balanced` fan-out can spend its two
slots on providers that call the real vendor APIs with a bogus key, and the stub's answer — and with
it the clamp assertion — depended on ambient credentials and the network. The failing line was the
`structuredContent` unwrap: with the other providers in the fan-out the tool returned an error
result instead.

Fix: the test pins the provider set, so the answer comes from the stub alone in every environment:

```swift
"SEARCH_DISABLED_PROVIDERS":
    "tavily,brave,mojeek,exa,open_web_search,parallel,duckduckgo,startpage",
```

## B28 `testDeeplyNestedContainersDoNotCostQuadraticTime` — my timing bound flaked

The test's own bound was 1 s. The linear implementation takes 0.28 s idle but took **1.16 s** on a
loaded machine, which is the intermittent single failure seen in round 39 and again while verifying
this change. The discriminating gap is 0.28 s (linear) versus 7.19 s (quadratic), so a 1 s bound was
measuring the scheduler, not the code — exactly the mistake B35 exists to warn about.

Fix: the bound is 4 s, which still fails the quadratic implementation by a wide margin (7.19 s) while
leaving the linear one a 3.4× margin under load. The reasoning is in the test.
